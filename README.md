# FixFlow Maintenance & WhatsApp Dispatch Portal

Tenant maintenance ticket portal with WhatsApp notifications, technician dispatching, inventory management and analytics. Client-side React app (demo data stored in the browser).

## Run locally
```
npm install
npm run dev
```

## Build
```
npm run build   # outputs to dist/
npm run lint    # type-check
```

## Deploy on Vercel
Import the repo. Settings are in `vercel.json` (Framework: Vite, Output: `dist`). No environment variables needed.
